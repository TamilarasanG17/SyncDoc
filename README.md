# SyncDoc – Collaborative Document Engine

# SyncDoc is a real-time collaborative document platform designed to allow multiple users to edit the same document simultaneously without destructive synchronization conflicts.

# Key Features

-Real-time multi-user collaboration
- AST-based document structure
- Yjs-based synchronization
- WebSocket communication
- Document-specific collaboration rooms
- Late-user state synchronization
- Nested node validation
- Circular relationship detection

# Tech Stack

Node.js · Express.js · MongoDB · Mongoose · WebSocket · Yjs · React

# Goal

To build a reliable collaborative editing system that combines **AST-based document modeling with CRDT-powered real-time synchronization for consistent multi-user editing.
